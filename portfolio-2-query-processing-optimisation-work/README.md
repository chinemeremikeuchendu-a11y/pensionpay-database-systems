# Portfolio 2: Query Processing and Optimisation

## 1. Project Overview

This portfolio focuses on SQL query processing, execution and optimisation using PostgreSQL 18.

The project builds on the PensionPay Fintech Pension Contribution Collection and Management System developed in Portfolio 1.

It demonstrates how database queries can be designed, executed and optimised to retrieve meaningful information from pension contribution records.

## 2. Project Objectives

- Develop and execute SQL queries to retrieve pension data.
- Analyse employee and employer pension contributions.
- Generate contribution summaries and reports.
- Identify pending pension contributions.
- Examine query execution plans using EXPLAIN and EXPLAIN ANALYZE.
- Apply indexing techniques to improve query performance.
