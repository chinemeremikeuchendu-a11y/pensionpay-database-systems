# Portfolio 4: NoSQL and Advanced Data Models

## Project
PensionPay Database System

## Objective
To demonstrate the use of NoSQL database technology for storing and managing pension contribution information.

## Technology
MongoDB Community Edition

## Activities
1. Design a MongoDB document model.
2. Implement pension contribution documents.
3. Demonstrate document insertion and retrieval.
4. Explain the suitability of NoSQL for PensionPay.

## Evidence
MongoDB scripts, implementation screenshots, query results, and technical documentation.
